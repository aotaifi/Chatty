# Fable NQS-architecture consult (2026-10-21, read-only) — consultant opinion, not instructions
- Diagnosis: the ViT tail error follows an ADDITIVE law, delta log a ~ eps/a with eps ~ 2-4e-7 (normalised psi) constant from a^2 = 1e-9 to 1e-13 (from the decade table): psi_fit = psi_t + eps x smooth, i.e. a displaced node. Generic for log-additive, sign-external ansatze (ViT, CNN, RBM/Jastrow tail nets): near-node amplitudes are cancellations, psi(x) = sum_y H_xy psi(y)/(E - H_xx). Reaching 0.01 at a^2 = 1e-12 needs eps 1e-8 (30x): not a sampling or capacity fix.
- Determinant/Pfaffian families (PP, RBM+PP, backflow/hidden-fermion Pfaffians): (i) cancellation is native (|Pf F(x)| small by near-dependent rows; node displacement = sign error, measured small); (ii) EXACT FAST-UPDATE RATIOS: one-swap ratio rank-2 O(N), double swap rank-4 O(N): all 2.3N one-hop ratios O(N^2) ~ one Pf evaluation; all (2.3N)^2 two-hop ratios O(N^3) (8x8 ~ one ViT forward; 14x14 ~ 1/15 of one ViT hop). "One more hop" stops being a cost catastrophe. Use the hidden-fermion form (fixed visible block + n_h hidden rows from a small CNN) to keep fast updates; fp64 inverse with periodic recompute; SR/minSR mandatory (O_k diverges near nodes).
- Design PfH1: a(x) = |Pf F(x)| exp(g(x)) |1 + alpha(x)(E_L^Pf(x) - E)|, E_L^Pf exact (O(N^2)); g, alpha small MLPs on (spins, log|Pf|, E_L^Pf, V, W). No recursion: each round re-trains F warm and refits g, alpha to phi*(s_k); a second Pf shell costs O(N^3).
- Training: stage A fixed-sign SR for Pf/RBM (diag shift 1e-3 -> 1e-4, N_s >= 4P); stage B g, alpha supervised to phi* with the error-map loss sum_bad |h| phi_x phi_y (cosh delta - 1) + lambda sum phi^2 (log a - log phi*)^2; sampling: walkers + ALL bad-bond neighbours + 20-30% tempered phi*^(2 beta); veto (a = 0) on X.
- Premise half right: sign steps do not need tail amplitudes (classification); the reported E_FN does (bad-bond ratios, weighted delta_rms ~0.02-0.03 needed on NN bad bonds for 1e-5). Way around: report E_FN of H_eff(s, r) with r from PfH1 and let the projector supply phi; finish with one Lanczos step on H_eff.
- Cheapest test T0 (no training, existing tables): E_FN(s_2, PP ratios) with/without veto [ViT 1.02e-4 / 9.1e-5]; decade-resolved weighted bad-bond log-ratio error of PP vs phi*(s_2), NN/NNN split, fitted eps; same for |Pf||1 + alpha(E_L^PP - E)| with one scalar alpha. Decision: eps(PP) within 2x of the ViT -> determinant bias dead; eps down >= 5x or (c) < 5e-5 -> T1 (refit g, alpha with PP in place of the ViT; PASS E_FN <= 1e-5, weighted delta_rms <= 0.03 in decades 1e-9..1e-12, KKT labels precision/recall >= 0.9 by weight).
- Literature to verify: Nomura-Imada PRX 2021; Moreno et al. PNAS 2022 (hidden fermions); Luo-Clark PRL 2019 (neural backflow); Misawa et al. 2019 (mVMC).

## Addendum: physics (same consultant)
- J2/J1 = 0.5: non-magnetic window (gapless Z2/U(1)-Dirac spin liquid or deconfined criticality); best parton picture: Gutzwiller-projected fermionic spinons with s+d pairing (Hu, Becca, Parola, Sorella 2013) = an RVB sum over singlet coverings; amplitude psi(x) = Pf[F(x)]; J2 breaks Marshall, so the sign is sign(Pf).
- Rare near-node configurations = destructive interference of the covering sum: ferromagnetic clusters that cannot pair into singlets ("spinon defects") and, above all, the codimension-1 surfaces where the Pfaffian changes sign (domain walls between Marshall-like sign sectors reconnected by J2). Critical state: weight does not thin out fast near them.
- Non-additivity: for a Pfaffian, I(b,b') is a rank-2 correction from G = F^-1; near a node F has a near-null vector spread over the lattice, G ~ u u^T/lambda_min, so G_ab is O(1) at any distance: long-ranged exactly near nodes (as measured). At J2 = 0 (Marshall exact, Jastrow-like) it is log-additive and local. Not capacity: the nodal structure of a projected-fermion state.
- ViT failure: log|Pf| diverges logarithmically at the nodal surface; a smooth log-space net smears the node; positive multiplicative corrections never move a node (Jastrow vs backflow lesson). PP residual non-local because a fixed F puts the node in the wrong place. phi*(s) vanishes on s's sign domain wall: tail and nodal surface are one object.
- Architecture: a(x) = |det F_{up,down}(x)| exp(J(x)), F_ij = f(r_i - r_j) + B_ij(x): f = s+d pairing warm-started from our PP or the Hu 2013 parton (global, node-defining structure, all long-range I); B = LOCAL backflow (CNN receptive field 3x3-5x5 or hidden-fermion rows), zero-initialised, only to move the nodal surface to s's expelled face; J = the existing ViT as smooth bulk factor. One-swap neighbour = rank-r Woodbury update (r <~ 20-50): full shell ~1e8 flops at 14x14, ~100x below re-evaluating a ViT per neighbour.
- Training: 6x6 representability: bond loss sum w_xy (log r - log r*)^2, w = |H_xy| phi*_x phi*_y, hinge on bonds into Z; sample x ~ phi*_x sum_y |H_xy| phi*_y (walker-neighbour measure). At scale: fixed-sign SR + Hellmann-Feynman FN term; SR/minSR, shift 1e-4..1e-3, lr 0.02-0.05 on f, B; 1e-3 on J; >= 4k samples; no Adam.
- Premise: the loophole is GENERATING the tail from structure: with a determinant, near-node amplitudes are small because the node is near; sign(det F) is a sign prior whose flip is a node move, making sign and amplitude one update.
- Decisive 6x6 test (~3 A40-h): target phi*(s_2); arms (i) PP f only; (ii) f + local backflow (RF 3x3, 5x5); (iii) (ii) + ViT J; control (iv) ViT alone with the same walker-neighbour sampling. Pass: bad-bond log-ratio error <= 0.03 for a^2 in [1e-11, 1e-9] and E_FN(s_2, net ratios) <= 1e-5; diagnostics: residual rms I at distance >= 2.8 <= 0.15, error share on X_0.1, sign(det) alignment with s_2 by decade. Fail only if (ii) > 3e-5 and decade error below 1e-11 > 0.1.
