# Ratio-input add-on network (ratnet), 6x6 consolidation test — 2026-11-18

## What was built
An add-on r(x) on the frozen guide A_0 (ppbf), ln A = ln A_0 + r, fitted to the fixed-node target ln A_1.
r = MLP( (1/16) sum_b mask_b * phi(ln rho_b, h_b sgn_b min(rho_b,20), sgn_b, J1/J2, spins) ), with rho_b = A_0(y_b)/A_0(x) the one-hop ratios.
Output layer starts at 0, Adam, 55000 steps, fresh stratified rows. Code: branch j1j2-ratnet (ratnet_lib.py, consol_fit.py arm 'ratnet').
Result: retention_N 0.7285 (seed 1, job 18045653); broken control with shuffled inputs 0.0080 (18045654).
Spins-only ViT add-on on the same loss: 0.056 (Gauss-Newton), 0.057 (Adam).

## Why
The target is r* ~ l + 1.307 f_J, l = ln|1 + alpha(E_L[A_0] - E)|, E_L = D0 + sum_b h_b sgn_b rho_b.
E_L is linear in the ratios, so a per-bond layer plus a sum represents it exactly; a spins-only net must rebuild A_0's ratios.
Evidence for the spins-only failure: the best linear readout of its features correlates <= 0.25 with r*; Adam on fixed rows memorises (train -82%, held-out +28%).

## Rejected
- Better optimiser for the ViT: Adam = GN (0.057 vs 0.056). The optimiser was never the block.
- Explicit formula add-on (no training): 0.946, but it is the Jacobi factor written one hop short, not a learned copy.
- Inputs frozen at round 1 for later rounds: round-2 retention 0.836, so inputs must refresh each round.

## Three things to understand
1. Retention_N = (N(A_0) - N)/(N(A_0) - N(A_1)), exact fixed-node grade on 6x6; 1 = full copy of A_1's gain.
2. The broken control (inputs from a different row of the same decade) is what makes 0.73 mean "the ratios carry it".
3. Cost catch: at 8x8 with a backflow guide, each amplitude needs ~NB evaluations of A_0 for its ratios.
