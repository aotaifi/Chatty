description: Deliver figures in presentable paper style on the first try, not quick diagnostics
metadata:
  type: feedback
---

When showing the user a plot, make the presentable version directly: few curves (only what carries the message), points with thin lines, panel letters, paper style (log10-exponent axes), legend not overlapping data or labels, plain-language labels; put parameter dependence in a sentence instead of extra curves. Check the rendered image before sending.

**Why:** the user said a cluttered diagnostic plot wasted their time and tokens: "next time ... go for the better version" (2026-10-05).
**How to apply:** for any figure in the J1-J2 project (see [[j1j2-paper-on-overleaf]]), render, inspect, fix layout issues, then send once.
