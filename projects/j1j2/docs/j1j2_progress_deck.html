The loop: stored sign × network amplitude, one Jacobi level per round

guide\(\psi_k(x)=S_k(x)\,|B_k(x)|\qquad S_k=\text{sign network},\ \ B_k=\text{pair-product network}\)
fixed node\(H_{\rm FN}[\psi]=H^{\rm kept}+{\rm diag}\,V_\psi,\quad V_\psi(x)=\sum_{y\ \rm blocked}|H_{xy}|\,\Big|\frac{\psi(y)}{\psi(x)}\Big|,\quad E_{\rm FN}=\lambda_{\min}(H_{\rm FN})\ge E_0\)
Jacobi target\(T_k=|B_k|\,e^{\,c\,f_J[B_k]},\quad f_J(x)=\ln\sum_{z\ \rm kept}|H_{xz}||B(z)|-\ln\big[(H_{xx}+V_B(x)-E')\,|B(x)|\big]\)
copy\(B_{k+1}=\arg\min_\theta\ \mathcal L\big(B_\theta,\,T_k\big)\qquad\text{label-free: } T_k \text{ exact at any sampled } x\)
sign step\(S_{k+1}=\operatorname{sgn}\big[(1+\alpha(H-E))\,\psi_k\big]\ \to\ \text{stored in the sign network}\)
readout\(\text{FN-GFMC with guide } (1+\alpha(H-E))\,\psi_k\qquad (p=1\ \text{Lanczos step})\)
