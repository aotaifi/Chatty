# Training/evaluation audit of "no amplitude network is precise enough on the tail" (Fable, 2026-10-21, read-only consult)
Paths: cx = experiments/compress_6x6; runs = /project/theorie/a/A.Otaifi/chatty_compress6/runs. [M] = measured from the raw files or re-derived from the tables with numpy (reproduces every eps of cx_t0b.json to 3 digits); [C] = read in code; [I] = my inference.

**Verdict.** T0/T0b are correct evaluations and "fixed-pairing nodes are not automatically right" stands (T0 kill valid for that claim only). The further inference "a precise tail is just a better variational state, Pfaffian route dead" does not follow: every network compared was trained on an L2-type objective (VMC energy; or the ViT refit's phi_x phi_y-weighted log loss, which equals the additive L2 loss where errors are small), and all six show one error profile. [M] 80-91% of the squared error |a_net - phi*(s_2)|^2 sits at a^2 < 1e-10, which holds 2.4% of the weight (ViT 0.88, refit ViT 0.91, PP 0.80, RBM+PP 0.82, B2 0.68, B1 0.46); the additive error per configuration at decade -11 is 2.1-2.3x sqrt(L2/N_conf) for ViT, refit ViT, PP, RBM+PP and B2 (B1 1.7). So "eps tracks dE" is eps ~ sqrt(L2): the signature of the objective class, shared by ViT and pairing families, and blind to representability. [M] The ViT refit is not converged; it is a damping-cap stall after ~30 productive steps on 384-sample batches. A tail-flat objective (what the loop needs anyway, since it supplies phi*) was never run on any network; it would need ~9x less L2 improvement than the VMC route (the tail holds 89% of the ViT's L2) [I]. Pfaffian+backflow is untested; the 2-4 slice-h test in Q5 decides before the route is closed.

**Q1. ViT refit to phi*(s_2)** (runs/refresh_17409419/vit/cx_reanchor.json, seed 1 in refresh2_17409866/vit_s1)
- Converged? No. [M] hist: 28/200 steps accepted (seed 1: 35/200); lam_rel reached its cap 1e2 by step 30 and sat there for 158/200 steps (153/200); accepted steps after step 26 move the parameters by |dlt| 5e-6..2e-5 against 3e-2 early (cx_reanchor.py:281-283 multiply lam_rel by 4 per rejection, cap 1e2, so the step shrinks to a tiny gradient step). Rejected trials are consistently worse on the fixed acceptance set (median L_try - L = +1.0e-6, min +5e-9; none better): the batch direction is anti-correlated with the 4096-sample validation gradient, i.e. sample noise, not a minimum [I]. The "flat held-out loss over 4 checks" is flat because the parameters stopped moving. Loss after step 30: 6.62e-4 -> 6.618e-4.
- Could the loss see the tail? Measure [C]: samples from Q = 1/2 |phi*| n + 1/2 node-Dirichlet weight, reweighted by iw = phi*^2/Q to the phi*^2 metric (cx_lib.proposal_q, cx_reanchor.py:132-137, 157-159, 166); bonds: all valid bonds (edges='all', line 156), weight |h| e^{la_y - la_x}, so the loss is sum phi*_x phi*_y |h| (dlog)^2 + 0.1 x value variance. Decades [M]: phi*^2 weight 7.8% at a^2 < 1e-10, 1.9% below 1e-11; the |phi*| half is 63% tail but its ESS after reweighting is 9.5% (so ~18 effective tail samples of 192 per batch). The loss VALUE is tail-dominated (weight x error^2: ~75% from decades -10..-13), so the gradient points at the tail but is estimated from ~20-30 effective tail configurations per step out of 1.5e7 tail orbits [I].
- Optimiser/steps/samples [C,M]: Gauss-Newton in sample space (3456 rows, 154,980 parameters), lam0 1e-2, trust radius 0.5 x 0.042 = 0.021 (never binding after step 6), B=384 x 8 bonds, 200 steps x 4.5 s. Total 77k configurations seen, 11k before the stall; the PP VMC saw 6.1M samples, RBM+PP 12M. Not adequate.
- Accept rate 0.14 in 15 min: yes, a training failure of the "stalled optimiser" kind (fixed validation set + damping cap + 384-sample directions). Its result (decade -10/-11/-12 error 0.043/0.107/0.216 against 0.064/0.181/0.420 for the plain ViT, 1.5-2x) is a lower bound on what the ViT can do, not a ceiling.

**Q2. PP / RBM+PP / B1 / B2** (chatty_rbmpp6/runs/*/train.json, results/rbmpp_6x6/README.md)
- [M] PP (rpT1_pp_17163493): SR, shift 1e-3, 2048 chains, 3000 steps, lr 0.05->0.01; E flat from step 750 (-0.503661) to 3000 (-0.503683 +- 5.5e-6 over the last 250); converged within noise, dnorm still 1.4e-3. RBM+PP A (rpT4_sr2_17164867): SR, shift 0.02, 8192 chains, 1500 steps; last 250 steps -0.503727 +- 2.6e-6, dnorm 5.7e-4: converged. "Optimiser-limited" refers only to the published simple-projection number (1.8e-5 short); with the full projection A equals the published 4.5e-5. B2/B1 (rpT3d_17164043 steps 95/70, lr 0.05, dnorm 1.2e-2): unconverged by design.
- Does "eps tracks dE" follow from the objective? Largely yes [M,I]: all five VMC states and the refit ViT have the same error profile (L2 share per decade above; additive error falling 1.5-1.7x per decade while a falls 3.16x, so delta ~ a^0.4 for all). eps = rms x 10^{d/2} is then (1.2-1.8) x sqrt(L2/N_conf) for all six (ViT 1.77, refit 1.22, PP 1.59, RBM+PP 1.41, B2 1.66, B1 1.47). Any L2-trained state, of any architecture, must land on this curve. T0b therefore tests the objective, and T0's eps clause too; neither tests whether a determinant with backflow can hold a tail-flat profile when trained on one.

**Q3. Evaluation (cx_t0.py:49-58, cx_t0b.py:133-142)** - no bias found that changes the comparison.
- Offset [C,M]: one global phi*^2-weighted shift; per-decade means are 0.001-0.005 in the bulk, so alignment is fine. In the tail the mean is -0.05..-0.55 (networks underestimate deep amplitudes; refit ViT +0.26 at -15, i.e. smeared nodes), but scatter dominates rms at every decade (ViT -12: rms 0.42, scatter 0.40): eps is scatter, not bias.
- Decade binning by phi*(s_2) [C]: phi* is 9.15e-7 from E0, fine. eps = rms x 10^{d/2} uses the decade's lower edge in a, so it underestimates the true additive rms by 1.3-1.6x [M], identically for all bases: no comparison bias. Normalisation [C]: norm_la gives sum n a^2 = 1 per base, right. Clipping a >= 1e-15 (st6_sector.py:237) [C]: only matters for the veto (lb - 40), which becomes a <= 1e-15 instead of 0, a suppression >= 1e8: no effect.
- One in-sample caveat [C]: the refit ViT's row is evaluated on all orbits, 80% of which were eligible for training; with 1e4 of 1.6e7 orbits seen this is negligible.

**Q4. Is the T0 kill rule a valid test of Pfaffian+backflow?** No [I]. It tests a fixed-pairing PP, VMC-trained, with no backflow, read on a tail its training never weighted; by Q2 its eps is pinned to sqrt(L2) like the ViT's, so "within 2x" was the only possible outcome at equal L2 (and PP's L2 is 0.75x the ViT's, hence 0.78). It kills "fixed-pairing nodes are automatically right" (I agree: PP's deep tail is biased low by 0.27 at -15 like the ViT's). The (c) clause is a one-hop quantity, as the lead noted. The route's actual claim (a node-moving ansatz trained on the tail) was not exercised.

**Q5. Cheapest fair test: tail-flat supervised fit on exact tables (2-4 slice-h, all machinery exists).**
- Objective: fit log phi*(s_2) with configurations drawn stratified by decade (equal count per decade -5..-13, uniform within the decade; the decade table exists), loss = per-configuration (log A - log phi*)^2 plus the bond term with weights renormalised per decade; the acceptance/held-out set stratified the same way; >= 2048 samples per step; minSR as now but with lam cap 1 and batch 2048, or Adam lr 1e-5 as a control; run until the stratified held-out loss is flat with >= 50% acceptance (so the stall of Q1 cannot be mistaken for convergence), <= 30 min per arm.
- Arms: (i) the ViT (same net); (ii) PP f-matrix only (630 real parameters); (iii) PP + 3x3 local backflow, if (ii) is set up. Two seeds for whichever arm decides.
- Readouts: count-weighted rms log error per decade, bond error per decade, E_FN(s_2, ratios) one solve, the decade splice.
- Rule: "training objective" is the cause (representability claim refuted for that arm) if decade -11 rms log error <= 0.03 with bulk (>= -8) <= 0.01; the claim stands for that arm if a converged stratified fit (acceptance >= 50%, lam below cap, 2x more samples changes the tail error < 10%) still gives >= 0.1 at -11. Physics pass stays E_FN <= 1e-5 (current splice: fitted above -9, exact below gives 5.8e-6, so the whole gap is these decades).
- Cost: ~15-30 min fit + 14 min table + 2 min solves per arm on an A40 slice; 3 arms x 1 seed + 1 repeat = 2-4 slice-h. Note for later: stratified sampling exists only at 6x6; at scale it would need tempered walkers, which is a separate question from representability.
